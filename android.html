Health K' pour Android

Synchronisation automatique avec ta Galaxy Watch via Santé Connect

Télécharger l'appli (APK)
Fichier health-k.apk · 4,9 Mo
  1. Touche Télécharger. Si Chrome affiche « Ce type de fichier peut endommager votre appareil », touche Télécharger quand même.
  2. Ouvre le fichier téléchargé (notification ou dossier Téléchargements).
  3. Si Android le demande : Paramètres → Autoriser cette source, puis reviens en arrière et touche Installer.
  4. Si Play Protect affiche un avertissement : Plus de détails → Installer quand même (l'appli n'est pas sur le Play Store, c'est normal).

Ouvre cette page directement dans ton navigateur (Chrome, Brave, Samsung Internet), pas depuis une autre appli, sinon le téléchargement peut rester bloqué.

Le téléchargement reste bloqué ? Le fichier est souvent déjà là : ouvre Mes fichiers → Téléchargements et touche le fichier health-k le plus récent.

Appli pour la montre

Galaxy Watch 4 ou plus récente : BASDAI complet, chrono de raideur, température, injection, dernière saisie, IMRALDI, prochains RDV et une tuile.

Télécharger l'appli montre (APK)
Fichier health-k-montre.apk · à installer sur la montre depuis le téléphone

Samsung ne permet pas d'ouvrir ce fichier directement sur la montre. On l'installe une fois avec le mode développeur, en 10 minutes, depuis le téléphone seul. Il faut aussi la dernière version de l'appli du téléphone (bouton du haut).

1. Sur la montre

  1. Paramètres → À propos de la montre → Informations sur le logiciel : touche 7 fois « Version du logiciel » jusqu'au message « Mode développeur activé ».
  2. Reviens dans Paramètres → Options de développement : active Débogage ADB, puis Débogage via Wi-Fi (la montre et le téléphone doivent être sur le même Wi-Fi).
  3. Touche Débogage via Wi-Fi → Associer un nouvel appareil : la montre affiche un code à 6 chiffres et une adresse du type 192.168.1.23:41234. Laisse cet écran ouvert.

2. Sur le téléphone

  1. Touche Télécharger l'appli montre ci-dessus.
  2. Installe l'appli gratuite Wear Installer 2 depuis le Play Store, et ouvre-la.
  3. Entre l'adresse IP de la montre (la partie avant les « : »), puis associe-la avec le port et le code affichés sur la montre.
  4. Choisis Custom APK (fichier personnalisé), sélectionne health-k-montre.apk dans Téléchargements, et touche Installer. Accepte sur la montre si elle le demande.
  5. C'est installé : sur la montre, désactive Débogage ADB (Options de développement) pour la batterie.

3. Premiers pas

  1. Ouvre Health K' sur le téléphone, puis sur la montre : elles se relient toutes seules (« Synchronisé à … »).
  2. Tuile : depuis le cadran, glisse vers la gauche jusqu'au bout, touche + Ajouter, choisis Health K'.

Mises à jour de l'appli montre : rares. Il suffit de refaire la partie 2 (le code d'association change à chaque fois).
