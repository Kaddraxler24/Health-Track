# Health K' (ex-Suivi Santé)

Application web installable (PWA) de suivi santé : scores BASDAI, biologie, poids et composition corporelle, traitement, consultations.

- Ouvrir dans Chrome sur Android → menu ⋮ → **Installer l'application**.
- Fonctionne hors connexion après la première ouverture.
- **Aucune donnée personnelle dans ce dépôt** : les données sont importées depuis un fichier local (Plus → Importer) et restent uniquement dans le navigateur du téléphone. Pensez à faire Plus → Exporter régulièrement pour sauvegarder.
